# Data Sources

IP Security Intelligence correlates information from multiple public and optional threat intelligence sources.

## Registration and Ownership

- RDAP
- WHOIS

## Network Intelligence

- ASN
- BGP
- Network ownership
- Network prefix

## DNS Intelligence

- Reverse DNS / PTR records

## Geolocation

- Country
- Region
- City
- ISP
- Organization
- ASN

## Threat Intelligence

- VirusTotal
- AbuseIPDB
- GreyNoise
- AlienVault OTX

## Internet Exposure

- Shodan InternetDB
- Open ports
- Hostnames
- Vulnerabilities
- CPEs
- Tags

## DNS Blocklists

- Spamhaus ZEN
- SpamCop
- Barracuda Reputation Block List

## Important

Results depend on the target IP, provider availability, API configuration, and the time of investigation.

A single reputation result is not treated as definitive proof of malicious activity. The tool correlates multiple sources before producing its risk assessment.
